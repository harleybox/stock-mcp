# 回测研究

网上流传的交易方法,拿数据验一遍。三份脚本都只依赖 yfinance,可以直接跑。

## 共同的规矩

- **安慰剂对照**:同一套进出场规则,套在随机挑的日子上跑 30 轮。真信号要明显好过随机日,才算有信息。只看「回测赚了多少」没有意义 —— 过去十年随便哪天买美股大概率都赚。
- **不用未来数据**:信号在收盘确认,次日开盘才进场。
- **跳空按开盘价成交**:开盘已经越过止损,就按开盘价算,不假设止损价一定成交。
- **扫参数网格,不看单格**:一个参数格的漂亮数字不算数。
- **|t| < 2 一律当作没区别**。

## 结论一览

下面的数字是 2026-11-09 用所列命令跑出来的(数据截止日不同,你跑出来会略有出入)。

| 方法 | 说法 | 实测 | 脚本 |
|---|---|---|---|
| Larry Williams 外包线 | 视频称 BTC 胜率 94% | 12 只 ETF、10 年、1190 个信号:5 个参数格全部和随机日无区别(z 0.15~1.12);单边成本 0.05% 时每笔为负 | [lw_outside_day_bt.py](lw_outside_day_bt.py) |
| 三倍量阳线 + 基准线回踩 | 放量阳线后缩量回踩再站回就买 | 13 只 ETF、10 年:量比 1.0~3.0 × 四种出场共 16 格,全部和随机日无区别(\|z\| ≤ 1.57);「三倍量」只出现 6 次 | [vol3x_bull_bt.py](vol3x_bull_bt.py) |
| EMA 五线多头排列 | 20/30/40/50/60 全多头排列就持有 | 标普前 100 只(到手 97 只)、10 年:择时年化 9.0% vs 买入持有 14.9%(t = -1.36),加 0.05% 成本后 5.9%(t = -2.05);首次成立后买入,持有 1~60 天都不比同票同期买持好(配对 t 0.35~-1.44) | [ema_stack_timing_bt.py](ema_stack_timing_bt.py) |

一句话:三个都没有测出比「随便哪天买」更多的东西。

## 复现

先按根目录 README 建好 `.venv`,然后在仓库根目录执行(也可以让 AI 通过 `run_study` 工具直接跑):

```bash
.venv/bin/python research/lw_outside_day_bt.py --set etf --placebo 30
```

```bash
.venv/bin/python research/vol3x_bull_bt.py --set etf --placebo 30
```

```bash
.venv/bin/python research/ema_stack_timing_bt.py --set stock --limit 100
```

每个脚本的文件头写了完整规则、口径和可调参数(`--help`)。

## 局限

- 成分股是当前名单,有幸存者偏差。所以对照组用的是同一批标的(偏差在差值里抵消),或者直接用 ETF。
- yfinance 的复权日线,没有盘中数据;止损是否在盘中触发按日线高低点判断。
- 样本是美股为主的近十年,基本是牛市。
